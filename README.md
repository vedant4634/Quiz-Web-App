# Quiz Web App 📝

A simple Quiz Web Application built using **HTML, CSS, and JavaScript**.  
This project focuses on **JavaScript logic**, especially option selection and score calculation.

---

## 🚀 Features

- Multiple-question quiz flow  
- Next & Previous navigation between questions  
- Option selection with correct/wrong highlighting  
- Score calculation based on correct answers  
- Final result screen displayed after submission  

---

## 🛠️ Technologies Used

- **HTML** – structure of the quiz  
- **CSS** – basic styling and layout  
- **JavaScript** – logic for:
  - Option selection  
  - Preventing multiple answers  
  - Score calculation  
  - Navigation between questions
